1. Overview & Commitment

At Geba AI, financial data protection is core to our service. This Privacy Policy details how our mobile application, backend REST APIs, and enterprise web management tools collect, store, and safeguard transaction receipt information. We adhere strictly to Ethiopian digital financial security standards, Google Play Developer Policies, and global data privacy principles (GDPR).

  • Zero Data Monetization: We never sell, rent, or trade personal or corporate receipt data to third-party ad networks or brokers.
  • Strict Purpose Limitation: Information collected is exclusively used to verify receipt authenticity and prevent fraudulent duplicate transactions.
📄

3. AI & Bank Provider Verification

Geba AI pairs Google Gemini Vision OCR with native provider adapters (CBE, Telebirr, Abyssinia, Dashen, BoA, Awash, Zemen) to validate payment authenticity:

  • Stateless AI Processing: Uploaded images are processed in stateless RAM buffers for OCR extraction and are NOT used to train public AI models.
  • Provider API Querying: Extracted reference IDs are validated against bank confirmation feeds via secure TLS 1.3 API queries.
  • Algorithmic Fraud Signals: Automatic checks inspect font consistency, pixel distortion, and duplicate reference reuse.
🔒

4. Security & Encryption Standards

We deploy defense-in-depth infrastructure safeguards to prevent data breaches and unauthorized access:

  • TLS 1.3 Transport Security: All API communication between mobile devices, servers, and bank endpoints is encrypted in transit.
  • AES-256 Storage Encryption: Database records and stored receipt assets are encrypted at rest with managed encryption keys.
  • Enterprise Tenant Isolation: Multi-tenant enterprise data is strictly segregated using isolated workspace schemas and role-based permissions (RBAC).
